## 🗂️ Topics & Exercises Covered
Here is a breakdown of the core concepts and code snippets included in this repository:

* **Basics & Datatypes**: Variables, numbers, booleans, and string operations (`01_first_python.py` - `04_number.py`)
* **Control Flow**: If-else conditional statements, `for` loops, and `while` loops (`09_if_statements.py`, `12_while.py`, `14_for.py`)
* **Data Structures**: Lists, tuples, and dictionaries (`06_list.py`, `07_tuple.py`, `11_dictionary.py`)
* **Functions & Modules**: Defining custom functions and organizing code with modules (`08_function.py`, `17_module.py`)
* **File Handling**: Reading and writing text files (`16_file.py`)
* **Object-Oriented Programming (OOP)**: Classes, constructors, and inheritance (`18_class_and_object.py` - `20_inheritance.py`)
